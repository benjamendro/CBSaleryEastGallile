# דשבורד שכר ותעסוקה — אשכול גליל מזרחי

דשבורד אינטראקטיבי (עברית, RTL) המציג **שכר חודשי ממוצע**, **מספר שכירים** ו**ממוצע חודשי עבודה**
לפי רשויות מקומיות ולפי ענפי כלכלה, לשנת 2024 — תמיד לצד הממוצע הארצי.

**לפתיחה:** `index.html` — קובץ HTML עצמאי אחד. אפשר לפתוח בכל דפדפן, לשלוח במייל או להעלות
לאתר; אין תלות בקבצים אחרים (הנתונים והלוגו מוטמעים בתוכו).

---

## מה יש בדשבורד

| מקטע | מה הוא מציג | פקדים |
|---|---|---|
| **מדדי מפתח** | ערך האשכול, הערך הארצי, הפער ביניהם, והרשות המובילה | מתעדכן עם בורר המדד |
| **השוואה בין הרשויות** | גרף עמודות של 18 הרשויות, עם קו ממוצע האשכול וקו הממוצע הארצי | סדר · גרף/טבלה |
| **השוואה בין ענפי כלכלה** | גרף עמודות אופקי של 51 קבוצות ענפים, עם אותם שני קווי ייחוס | אזור · צמצום הרשימה · גרף/טבלה |

**בורר המדד** בראש העמוד הוא גלובלי — הוא משנה יחד את כרטיסי המדדים ואת שני הגרפים.

**האשכול כיחידה אחת.** אין בדשבורד חלוקה לנפות: נפות צפת וגולן מוצגות יחד כ„אשכול גליל
מזרחי”, ולכן כל העמודות בגוון אחד. הנפות עדיין נקראות מקובץ המקור — `build_data.py` משתמש
בהן כדי לאמת שסכום השכירים ב-18 הרשויות תואם את סכום הנפות — אך אינן מוצגות.

**קווי הייחוס.** קו אפור = ממוצע האשכול, קו זהב = הממוצע הארצי. שניהם עוגנים קבועים שאינם
זזים עם הסינון. במדד *מספר שכירים* מוצג רק ממוצע האשכול, מפני שהערך הארצי הוא סך הכול ולא
ממוצע לרשות ואינו בר-השוואה על אותו ציר.

**שלוש דרכים לצמצם את רשימת הענפים** (51 ענפים אינם נקראים היטב בגרף אחד):

1. **טווח** — 10/15/20 הגבוהים, 10 הנמוכים, 10 גבוהים ו-10 נמוכים, או הכול.
2. **קיבוץ ענפים** — 16 קיבוצים המבוססים על סדרי הענפים של הלמ"ס, בתוספת קיבוץ „היי-טק”
   החוצה סדרים. אפשר לבחור כמה קיבוצים יחד.
3. **בחירת ענפים** — בחירה ידנית מרשימה עם חיפוש.

לכל גרף יש **תצוגת טבלה** מקבילה שבה כל הערכים גלויים, וכן חלונית מידע (tooltip) בריחוף
שמציגה את שלושת המדדים יחד.

## מקורות ועיצוב

- **נתונים:** הלשכה המרכזית לסטטיסטיקה — עיבוד מיוחד מורכב מקובצי הכנסה מנהליים, 2024
  (`עיבוד לפי ענף ורשות בני דורמבט.xlsx`).
- **מילון ענפים:** `dicAnaf4SfarotMaster 2.xlsx` — ממנו נגזרים שמות הענפים והקיבוצים.
- **עיבוד והצגה:** מרכז הידע האזורי גליל מזרחי | מערבי.
- **עיצוב:** נגזר מערכת העיצוב של המרכז ב-`design/template/brand.css` (צבעים, טיפוגרפיה,
  רכיבים, מוטיב הפסיפס מהלוגו), על רקע לבן. צבעי הגרפים אומתו לנגישות עיוורון-צבעים מול
  רקע לבן: `#1C70A8` לעמודות, `#A8823A` לקו הארצי (CVD ΔE 20.1, ניגודיות ≥3:1).

## בנייה מחדש (כשהנתונים מתעדכנים)

```bash
pip install openpyxl Pillow
python3 dashboard/build_data.py   # xlsx → dashboard/data.json  (כולל בדיקות תקינות)
python3 dashboard/build.py        # data.json + template.html → index.html + artifact.html
```

| קובץ | תפקיד |
|---|---|
| `build_data.py` | קורא את קובצי ה-xlsx, מאמת סכומים מול המקור, וכותב `data.json`. **כאן** נמצאים שמות התצוגה של הענפים, הקיבוצים ושיוך הרשויות לנפות (לאימות בלבד). |
| `template.html` | העמוד עצמו — CSS, מבנה וקוד הגרפים. מכיל את הסמנים `"__DATA__"` ו-`__LOGO__`. |
| `build.py` | מזריק את הנתונים ואת הלוגו לתבנית ומייצר את שני הפלטים. |
| `data.json` | הנתונים המעובדים (נוצר אוטומטית). |
| `index.html` | **הפלט לשימוש** — קובץ עצמאי (נוצר אוטומטית). |
| `artifact.html` | אותו תוכן ללא עטיפת `<html>/<head>/<body>`, לפרסום כ-Artifact (נוצר אוטומטית). |

`build_data.py` עוצר עם שגיאה אם רשות אינה משויכת לנפה, אם קוד ענף חסר במילון, אם חסר שם
תצוגה לקבוצת ענפים, או אם סכום השכירים ברשויות אינו תואם את סכום הנפות שבמקור.

## הערות על הנתונים

- „אשכול גליל מזרחי” מוגדר כאן כ-18 הרשויות שבנפות צפת וגולן שבמקור. סכום השכירים בהן זהה
  לסכום שתי הנפות במקור (83,774).
- הפילוח לפי ענף מכסה 80,498 מתוך 83,774 שכירים באשכול (96%) ו-4,289,440 מתוך 4,418,600
  ארצית (97%). ההפרש נובע ממקרים שאינם מסווגים לענף או שמספרם קטן מכדי לפרסמו.
- לקבוצה „משקי בית כמעסיקים וארגונים חוץ-מדינתיים” אין נתון ברמת האשכול (מסומן `..` במקור).
- ממוצעי האשכול משוקללים לפי מספר השכירים ואינם מופיעים במקור אלא חושבו מנתוני הרשויות.
  אימות: אותו חישוב ברמת כל נפה בנפרד מחזיר בדיוק את הערכים שבמקור.
- „גולן” ברשימת הרשויות היא המועצה האזורית גולן, להבדיל מנפת גולן.
