# QA project context — דשבורד שכר ותעסוקה, אשכול גליל מזרחי

תשובות לשאלות הגילוי של `playwright-automation` ו-`exploratory-testing`.
קובץ זה הוא המקור; אין לחזור על השאלות בסשן חדש.

## מה נבדק

**שני קובצי HTML סטטיים עצמאיים**, שנבנים מאותם נתונים באותה ריצה:

| | קובץ | מה יש בו |
|---|---|---|
| הדו״ח | `dashboard/index.html` | נרטיב מלא: מורה נבוכים, מגירות, שישה מקטעים |
| קונסולת BI | `dashboard/console.html` | גרפים בלבד: שני טאבים, שישה פאנלים |

**אין שרת, אין API, אין התחברות, אין build step.** הנתונים והלוגו מוטמעים בקובץ.
מכאן שלושה חלקים של `playwright-automation` **אינם חלים** ובמכוון אינם ממומשים:
`storageState` ואימות רב-תפקידי (אין משתמשים), `page.route` ומוקים (אין רשת),
ו-`webServer` (הקבצים סטטיים; הסוויטה מגישה אותם ב-`http-server` על פורט מקומי,
כדי ש-`baseURL` ו-`toHaveURL` יעבדו כרגיל ולא מול `file://`).

## Playwright — תשובות הגילוי

1. **TypeScript** — כן.
2. **דפדפנים** — Chromium בלבד. זה הדפדפן היחיד שמותקן בסביבת הריצה
   (`/opt/pw-browsers`), ו-`team_maturity: startup` ממילא ממליץ על כך.
3. **סוויטה חדשה** — אין מיגרציה מ-Cypress/Selenium.
4. **שני „אתרים”** — הדו״ח והקונסולה. אותם נתונים, שתי מעטפות. מכאן פיקסצ׳ר
   משותף ואובייקט קונפיגורציה לכל דף (דפוס `multi-site-architecture` בגרסה מוקטנת).

```
team_maturity: startup
```

## אזורי סיכון ידועים

מה שכבר נשבר כאן בעבר, ולכן ראוי לתשומת לב ראשונה:

1. **RTL ו-bidi.** ‏`text-anchor` מתנהג הפוך תחת `direction:rtl`; מספרים עם סימן
   (‎`+9.4%`, `−12.0%`) מתהפכים בלי `unicode-bidi:isolate`. שתי תקלות אמיתיות
   בעבר. **שתי התבניות פותרות את זה אחרת** — הדו״ח מנהל עיגון הפוך ידנית,
   הקונסולה שמה `direction:ltr` על ה-SVG.
2. **צירופי מצב.** חלק א׳: 3 מדדים. חלק ב׳: 3 אוכלוסיות × 2 תצוגות × 2 מצבי תמהיל.
   בקונסולה כל אלה כפול טוגל גרף/טבלה בכל פאנל.
3. **נתונים חסרים.** יסוד המעלה חסרה בכל לוחות הביטוח הלאומי; מטולה קיימת רק
   מ-2023. כל מסלול שמחשב „שינוי מאז 2016” חייב להתמודד עם `null` בבסיס.
4. **ציור מחדש מוחק מצב.** הפאנלים והמקטעים נמחקים ונבנים מחדש בכל שינוי בורר.
   הערת העורך ומצב העריכה חייבים לשרוד את זה.
5. **ההפרדה בין המקורות.** הכלל המחייב: לעולם לא ערך שכר של הביטוח הלאומי
   לצד ערך של הלמ״ס. בקונסולה זה נאכף מבנית (טאבים); צריך לוודא שזה מחזיק.
6. **ייצוא בארגז חול.** הורדות חסומות בתצוגת Artifact; יש נפילה להעתקה ללוח.
