# ניתוח שכר — אשכול גליל מזרחי

עיבוד של נתוני השכר והתעסוקה שנאספו לאשכול גליל מזרחי: העיבוד המיוחד של הלמ״ס
(`עיבוד לפי ענף ורשות בני דורמבט.xlsx`, 2024) ו־180 לוחות של המוסד לביטוח לאומי
(`relevant_tables.rar`, 2016–2024).

**הדוח:** [`report.html`](report.html) — פורסם גם כ־Artifact.

## מבנה

```
analysis/
  report.html              הדוח המלא (HTML עצמאי)
  btl-table-catalog.csv     קטלוג 180 לוחות ביטוח לאומי
  etl/
    parse_btl.py            פירסור הלוחות הגולמיים מה־xlsx
    build_master.py         נרמול מדדים, השלמות, תיוג אשכול
    lib.py                  עזרי שליפה וצבירה
    analyze.py              כל טבלאות התוצאה בהרצה אחת
    make_catalog.py         בניית הקטלוג
  output/                   טבלאות התוצאה (csv) + report_data.json
```

## הרצה

```bash
unar -o /d relevant_tables.rar          # שם הקובץ ארוך — נדרשת תיקיית יעד קצרה
cd analysis/etl
python3 parse_btl.py && python3 build_master.py && python3 analyze.py && python3 make_catalog.py
```

תלויות: `pandas`, `openpyxl`, `numpy`. הנתיב לארכיון המחולץ מוגדר כ־`/d/relevant_tables`.

## החלטות מתודולוגיות מרכזיות

**גבול האשכול = נפת צפת + נפת גולן.** בעיבוד הלמ״ס ל־2024, 18 רשויות האשכול מסתכמות
ב־83,774 שכירים — בדיוק סכום שתי הנפות (57,776 + 25,998). לכן סדרות ברמת הנפה משמשות
ייצוג של האשכול, ומספקות רצף 2016–2024 עם פילוח מגדרי, התפלגות הכנסה ומשך עבודה.
בדיקה חוזרת: סכום 17 הרשויות ברמת יישוב/מועצה = 92,419 מועסקים מול 92,252 לפי הנפות (0.2%).

**הנתונים עובדו מחדש מה־xlsx הגולמי.** `unified_all.csv` שסופק אינו משמש כבסיס, משום
שנמצאו בו שני פגמים: (א) בכל לוחות "מחוז ונפה" נכתב שם *הנפה* בעמודת המגדר, והפילוח
גברים/נשים אבד; (ב) חסרים בו 28 מתוך 180 לוחות המקור. המנתח כאן משחזר כל גיליון מטווחי
התאים הממוזגים (openpyxl) ולא בהשלמה קדימה, כך שהיררכיית הכותרות ותאי הגאוגרפיה מדויקים.

**כיסוי:** 175 מתוך 180 לוחות — 152 ישירות מה־xlsx, 23 מ־`unified_all.csv` (עם החזרת עמודות
הגאוגרפיה למקומן). 5 לוחות אבדו לגמרי (פגומים בארכיון וגם חסרים ב־unified_all): סוג המבוטחים
לפי מועצה אזורית 2019, סוג המבוטחים לפי מחוז ונפה 2017 ו־2021, שכר ממוצע וחציוני לפי יישוב
2017 ו־2019.

**שני מקורות, שתי שיטות ממוצע.** למ״ס וביטוח לאומי מסכימים על מספרי המועסקים (מתאם 0.996)
ועל ממוצע חודשי העבודה, אך נבדלים ב־14% ברמת השכר — עקבי עם כך שביטוח לאומי מחשב יחס
מצרפי ואילו הלמ״ס ממוצע פר־אדם. **אין להשוות רמות שכר בין המקורות**; מדדים יחסיים לארצי כן
(מתאם 0.979, מתאם דירוגים 0.980). כל השוואה בדוח נעשית בתוך מקור אחד.

## אזהרות בשימוש חוזר

- **התנגשות שמות:** "צפת" ו"גולן" קיימים גם כיישוב/מועצה אזורית וגם כנפה. חובה לקבוע את
  הרמה במפורש — אחרת מתקבל ניפוח של 138% במספר המועסקים בצפת.
- **יסוד המעלה** אינה בטבלאות ביטוח לאומי (סף 2,000 תושבים); היא כלולה בסכום הנפתי ובעיבוד הלמ״ס.
- **אין סמלי למ״ס בקובצי ביטוח לאומי** — הצימוד לפי שם בלבד, בניגוד לכלל הצימוד הכפול
  ב־`eshkol-matching/SKILL.md`. 17 ההתאמות אומתו ידנית; שתיים הן התאמות כתיב.
- הנתונים **נומינליים**, ללא ניכוי מדד המחירים.

## עיקרי הממצאים

1. השכר הממוצע באשכול = 80% מהארצי, ללא שינוי מ־2016. הפער מול תל אביב גדל מ־3,545
   ל־5,647 ש״ח לחודש (+59%).
2. השכר **החציוני** בנפת צפת = 93% מהחציון הארצי, מול מדד ממוצע של 84% — הפער נובע
   מהיעדר קצה עליון, לא מחולשת העובד החציוני. יחס חציון/ממוצע: 78% בנפת צפת מול 70.5%
   ארצית ו־66.4% בתל אביב.
3. ארבעה ענפי ידע (תכנות, פיננסים, מו״פ, אלקטרוניקה) — 5.6% מהמועסקים מול 10.9% ארצית —
   מסבירים 92% מפער השכר. הרכב ענפי ארצי היה סוגר רק 22% מהפער; שכר ארצי בכל ענף — 60%.
4. בחינוך (המעסיק הגדול, 14.3%), בחקלאות, בייצור מזון ובפלסטיק האשכול משלם 97%–103% מהארצי.
5. פער פנימי של פי 1.79: מ.א. גליל עליון 105.6% מהארצי (מקום 124/341) מול מסעדה 59.0%
   (מקום 327). 47% ממועסקי האשכול ברשויות מתחת ל־80% מהארצי.
6. 2024: ירידה של 4.0% במספר המועסקים באשכול (נפת צפת −5.3%) מול עלייה של 0.9% ארצית.
